Architecture

One loop. Total control.

Every request flows through the same pipeline: a brain, persistent memory, an audit log and an approval gate between you and every risky action.

With God Mode on, approvals are granted automatically — but every action is still written to the audit log, so nothing disappears.

  • Approval gate on every risky action
  • Full audit trail with timestamps
  • Kill switch: /stop, always available
  • Files confined to nova_workspace
